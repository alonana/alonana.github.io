## Some takeaways from today

* When moving to higher magnification, I should increase LED intensity
* Using the fine focus, I can see different layers in the specimen.
* No matter how much I've tried, I could not see one image in the binocular. I see 2 images
* I still wait to gain more experience before using the X1000 magnification with oil
* I don't really understand how to clean stuff up yet

As for using the camera:

* The camera autoadjusts to the LED intensity, unlike using my own eyes
* The sensitivity of focus is much higher, I need to invest more time to get a good image.
